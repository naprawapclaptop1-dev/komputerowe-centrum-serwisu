  makieta płyty. Dawny model 2D przeniesiono do rozwijanej sekcji pomocniczej.
- Główna fotografia ma przełączaną galerię: mikroskopia uszkodzonego układu,

  fotografie są zasobami lokalnymi istniejącego projektu. Zewnętrzne zdjęcia
  wymagają internetu; lokalne zasoby służą jako fallback.

POŁĄCZENIA SPRZĘTOWE — CO DZIAŁA W PRZEGLĄDARCE
1. Kamera/mikroskop UVC: getUserMedia, wybór kamery po udzieleniu zgody, podgląd
   na żywo wideo. HDMI wymaga grabbera USB widocznego dla systemu jako kamera.
2. Port szeregowy: Web Serial, wybór portu, wybór baud rate i odczyt surowego
   strumienia. Moduł nie wysyła nieznanych komend do przyrządów.
3. USB: WebUSB wybiera urządzenie po VID i opcjonalnym PID. Sam wybór urządzenia
   nie oznacza jeszcze obsługi jego protokołu ani odczytu pomiarów.
4. LAN / SCPI / VISA: wymaga lokalnego mostka Windows, ponieważ zwykła strona
   internetowa nie może otwierać dowolnych połączeń TCP do przyrządów.

WAŻNE OGRANICZENIA
- Wymagany jest HTTPS (lub localhost), aktualny Chrome/Edge i zgody użytkownika.
- Nie istnieje jeden uniwersalny protokół wszystkich mikroskopów, zasilaczy,
  multimetrów, oscyloskopów i programatorów. Do pełnej obsługi potrzebne są
  profile konkretnego producenta/modelu, VID/PID, dokumentacja protokołu i
  czasem oficjalny sterownik lub lokalny agent Windows.
- Zasilacz nie jest automatycznie włączany ani regulowany. Nie dodano komend
  wyjścia ON/OFF ani nieznanych poleceń SCPI. Sterowanie będzie dopiero po
  potwierdzeniu dokładnego modelu i bezpiecznych limitów.
- Programatory CH341A, RT809H, SVOD, EZP i inne wymagają oddzielnych adapterów
  producenta; WebUSB nie zastępuje sterownika ani protokołu.

CO DALEJ WARTO DODAĆ
- Lokalny Windows Hardware Bridge jako usługa z profilem urządzenia, logiem,
  certyfikatem lokalnym i API dla strony.
- Baza zgodności: producent, model, VID/PID, wersja firmware, interfejs,
  prędkość portu, protokół, funkcje odczytu i bezpieczne funkcje sterujące.
- Profile SCPI dla konkretnych zasilaczy, multimetrów i oscyloskopów, najpierw
  tryb tylko do odczytu i symulacja poleceń przed rzeczywistym sterowaniem.
- Zapis pomiaru wraz z modelem płyty, rewizją, punktem, warunkami testu,
  datą, przyrządem i zdjęciem przed/po naprawie.
- Nakładanie adnotacji na zdjęcie mikroskopowe: oznaczenia elementów, punkty
  pomiarowe, polaryzacja, uszkodzenia, ścieżki i obszary do reworku.
- Karta kalibracji przyrządów, ESD/BHP, kontrola temperatury i historia
  serwisowa sprzętu laboratoryjnego.
