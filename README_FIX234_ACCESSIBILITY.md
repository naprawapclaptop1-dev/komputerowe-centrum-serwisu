# FIX234 — ustawienia dostępności

Dostępne ustawienia lokalne: większy rozmiar tekstu, wysoki kontrast, podkreślanie linków i ograniczenie animacji. Zmiany dotyczą przeglądarki/urządzenia i nie są synchronizowane do D1. Dodano widoczny fokus klawiatury dla nowych elementów.

To pomocnicze ustawienia interfejsu, nie certyfikat WCAG. Pełny audyt z czytnikiem ekranu, klawiaturą, zoomem i testami ręcznymi pozostaje osobnym zadaniem.
