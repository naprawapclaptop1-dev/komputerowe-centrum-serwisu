NAUKA OD A DO Z — CHANGELOG 6.8.0 FIX185
Data: 2026-11-16
Nazwa: Centrum Diagnostyki Najwyższego Poziomu

NOWE SPECJALIZACJE
1. Windows Performance — WPR/WPA, ETW, CPU Ready Time, hard faults, Disk/File I/O i analiza rozruchu.
2. PCIe Protocol — AER, hierarchia Root Port/Endpoint, Link Training, ASPM, timeouty i retransmisje.
3. Windows Storage Stack — Storport, miniport, StorNVMe, StorDiag, reset/recovery i analiza kolejek.
4. PCB Failure Analysis — pad cratering, delaminacja, barrel crack, CAF, microsection oraz ESD handling.
5. Firmware Security — UEFI UpdateCapsule, ESRT, CHID, podpisy payloadu, anti-rollback i NIST Protect/Detect/Recover.
