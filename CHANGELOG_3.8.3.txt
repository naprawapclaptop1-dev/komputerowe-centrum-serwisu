NAPRAWA PC — AKADEMIA SERWISU PRO 3.8.3 — FIX WIĄZANIA D1 PO ID PAGES

- Dodano odczyt ustawień istniejącego projektu Pages przez Cloudflare API GET /accounts/{account_id}/pages/projects/{project_name}.
- Uwierzytelnienie pobierane jest z lokalnego Wrangler przez `wrangler auth token --json`; sekret nie jest wypisywany do logów.
- Odczyt API wymaga uprawnienia Pages Read.
- Produkcyjny binding `DB` jest odczytywany z `deployment_configs.production.d1_databases.DB.id`.
- Istniejąca baza jest dopasowywana po dokładnym UUID, nie po domyślnej nazwie ani zgadywanym schemacie.
- Jeśli ID z Pages, lokalnego wrangler.toml/json/jsonc i listy D1 nie zgadza się, operacja zatrzymuje się bez migracji.
- Jeśli Pages nie ma produkcyjnego bindingu DB, program nie wybiera innej bazy i podaje jasny komunikat.
- Wyszukiwanie po schemacie pozostaje wyłącznie awaryjnym trybem odczytowym.
- Nie tworzy nowego Pages project ani nowej bazy D1.
- Zachowano migracje, stronę, lekcje, materiały, Functions i automatyczny obserwator.

Testy offline nie potwierdzają zdalnego stanu konta Cloudflare. Pełna migracja i publikacja wymagają uruchomienia w katalogu użytkownika, gdzie Wrangler jest zalogowany do konta Akademii.
