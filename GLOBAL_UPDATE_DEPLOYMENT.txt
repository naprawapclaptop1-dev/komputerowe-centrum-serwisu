GITHUB RELEASES — KOMPUTEROWE CENTRUM SERWISU

1. Repozytorium tego programu jest przypisane na stałe: naprawapclaptop1-dev/komputerowe-centrum-serwisu.
2. Uruchom wyłącznie URUCHOM_TYLKO_TEN_PLIK.cmd.
3. Główny CMD wykonuje kontrolę, build, weryfikację, logowanie GitHub CLI (jeśli potrzebne), publikację i test publicznych assetów.
4. Publikator akceptuje zarówno owner/repo, jak i pełny adres GitHub URL. Przed publikacją normalizuje go do owner/repo i wymusza repozytorium przypisane do tego programu.
5. Każdy tag i release jest tworzony tylko wtedy, gdy jeszcze nie istnieje. Bez --clobber i bez nadpisywania starych plików.

Adres repozytorium: https://github.com/naprawapclaptop1-dev/komputerowe-centrum-serwisu
