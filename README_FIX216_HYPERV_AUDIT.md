# FIX216 — audyt izolacji Hyper-V

Dodano skrypt audytujący stan maszyny wyłączonej, brak kart sieciowych, wyłączone usługi integracji, Secure Boot, migawkę bazową, automatyczny start i ustawienia napędu. Audyt jest tylko do odczytu i nie uruchamia VM. Sam wynik audytu nie jest certyfikatem bezpiecznego sandboxa.
