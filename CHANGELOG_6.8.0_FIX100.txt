Data: 2026-11-08

NAPRAWIONO
1. Główny launcher nie sprawdza już Node.js wyłącznie przez where.exe node.
2. Dodano wspólny resolver sprawdzający PATH bieżącego procesu i zapisany PATH
   Windows, lokalizacje instalatora oraz typowe menedżery wersji Node.js.
3. Każdy znaleziony node.exe jest weryfikowany uruchomieniem --version.
4. Wybrany katalog node.exe jest dodawany tymczasowo do PATH bieżącego CMD,
   aby Node, npm i lokalny Wrangler były dostępne dla uruchamianych procesów.
5. Ujednolicono wykrywanie Node w głównym uruchamiaczu, skrócie testów FIX99,
   konfiguracji OpenAI i przygotowaniu Wrangler.
6. Dodano SPRAWDZ_NODE_FIX100.cmd do diagnostyki ścieżki i wersji Node.
7. Dodano WYKONAJ_TESTY_FIX100.cmd oraz testy regresji wykrywania Node.
