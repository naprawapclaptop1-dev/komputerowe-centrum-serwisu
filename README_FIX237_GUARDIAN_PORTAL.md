# FIX237 — panel opiekuna

- Uczeń tworzy jednorazowy kod, ważny 48 godzin. Opiekun prosi o połączenie, a uczeń zatwierdza lub odrzuca wniosek.
- Zaproszenie jest hashowane, jednorazowe i chronione przed równoczesnym podwójnym użyciem.
- Opiekun widzi jedynie zbiorczą liczbę postępów lekcji, podejść/zaliczeń egzaminów i certyfikatów. Nie uzyskuje dostępu do rozmów, notatek, haseł ani prywatnych wiadomości.
- Obie strony mogą cofnąć zgodę. Usunięcie konta usuwa powiązania.

Portal nie potwierdza wieku opiekuna i nie jest narzędziem formalnej weryfikacji tożsamości.
