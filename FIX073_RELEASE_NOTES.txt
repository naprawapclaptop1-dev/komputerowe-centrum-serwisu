KOMPUTEROWE CENTRUM SERWISU — FIX073
Wersja produktu: 1.0.0.69 (bez zmiany numeru produktu; FIX073 dotyczy aktualizatora, publikacji i strony WWW)

POPRAWKI AKTUALIZATORA I PUBLIKACJI
- Ujednolicono przepływ: klient korzysta z adresu GitHub Releases latest/download, a manifest wskazuje konkretny tag wydania.
- Wydanie jest najpierw przygotowywane jako szkic. Publikacja następuje dopiero po potwierdzeniu wszystkich assetów.
- Nie używa się --clobber. Istniejące pliki i opublikowane wydania nie są nadpisywane.
- Niekompletny szkic tego samego, nieopublikowanego tagu może być uzupełniony wyłącznie o brakujące pliki; istniejące pliki muszą mieć oczekiwany rozmiar.
- Do wydania dodawane są instalator, wersja portable, manifest Stable, manifest Beta, releases.json i SHA256SUMS.txt.
- Kontrola online sprawdza publiczny tag, oba manifesty, adres /releases/latest/download, HTTP 200 dla pobrań oraz sumy SHA-256.
- Program wyświetla bardziej jednoznaczny komunikat, gdy pierwsze wydanie nie zostało jeszcze opublikowane.

JEDEN ZIP / JEDEN CMD
- URUCHOM_TYLKO_TEN_PLIK.cmd pozostaje jedynym punktem wejścia.
- Automat przygotowuje narzędzia, najpierw synchronizuje źródła i publikuje globalną stronę Pages, następnie buduje aplikację, publikuje pierwsze wydanie, weryfikuje adresy i instaluje świeży program.
- Wymagana jest jednorazowa autoryzacja GitHub w przeglądarce oraz zgoda UAC dla instalacji.

DODATKOWA POPRAWKA ZGODNOŚCI
- Katalog releases.json jest tablicą wpisów Stable/Beta zgodną bezpośrednio z parserem C# programu.
- Manifesty XML i katalog JSON zapisywane są jako UTF-8 bez BOM.

OGRANICZENIA WERYFIKACJI W TYM PAKIECIE
- Wykonano statyczne kontrole źródeł, stron i struktury ZIP.
- Nie wykonano kompilacji Windows, publikacji GitHub Release ani wdrożenia GitHub Pages w tym środowisku. Wykona je główny CMD na komputerze Windows po autoryzacji właściciela repozytorium.
