AKADEMIA SERWISU PRO 3.9.10 — KONFIGURACJA CZATU HYBRYDOWEGO
================================================================

CO ROBISZ TY
------------
1. Uruchom URUCHOM_AKADEMIE.cmd.
2. Jeśli klucza OpenAI jeszcze nie ma w Cloudflare, CMD poprosi o jego wklejenie.
   Podczas wpisywania nie zobaczysz żadnych znaków — terminal nie wyświetla treści ani długości klucza.
3. Wklej cały klucz zaczynający się od sk- i naciśnij Enter.
4. Nie zapisuj klucza w pliku, nie wysyłaj go w wiadomości i nie wklejaj do strony.

Jeśli naciśniesz Enter bez wpisywania klucza, start będzie kontynuowany bez OpenAI.
Wtedy Akademia użyje Cloudflare Workers AI jako głównego dostępnego dostawcy.

JAK DZIAŁA AUTOMATYCZNE ZAPISANIE
---------------------------------
- Skrypt sprawdza, czy OPENAI_API_KEY już istnieje w projekcie Pages.
- Jeśli istnieje, nie pyta ponownie.
- Jeśli go brakuje, przyjmuje klucz w ukrytym polu terminala bez wyświetlania wpisywanych znaków.
- Przekazuje go do `wrangler pages secret bulk --env production` przez stdin (bez pliku tymczasowego).
- Weryfikuje, czy nazwa sekretu pojawia się na liście Cloudflare.
- Wartość klucza nie jest argumentem procesu, plikiem, wpisem w logu ani zmienną JavaScript strony.
- Dopiero potem uruchamia standardowy ONECLICK_AKADEMIA.js i publikację.

Wrangler Pages przyjmuje JSON dla `pages secret bulk`; konfigurator przekazuje JSON przez stdin i jawnie wskazuje środowisko `production`.
Dokumentacja: https://developers.cloudflare.com/workers/wrangler/commands/pages/

ZMIANA KLUCZA
-------------
Aby wprowadzić nowy klucz, uruchom USTAW_KLUCZ_OPENAI.cmd.
Skrypt ponownie zapyta o klucz w ukrytym polu, zapisze sekret i wykona standardowy
start oraz wdrożenie Akademii.

DOSTAWCY AI
-----------
1. OpenAI Responses API jest głównym modelem. Domyślny model: gpt-6.1-sol.
2. Gdy OpenAI zwróci błąd, limit, timeout albo przerwie strumień, serwer próbuje
   Cloudflare Workers AI: @cf/meta/llama-3.3-70b-instruct-fp8-fast.
3. Gdy oba modele są niedostępne, interfejs może przejść na lokalne wyszukiwanie
   w materiałach Akademii.

BINDING CLOUDFLARE AI
---------------------
ONECLICK_AKADEMIA.js automatycznie sprawdza i zapisuje binding `AI` w głównej
konfiguracji Wrangler oraz `env.production`. Nie musisz ręcznie wchodzić do panelu.
Po starcie watcher sprawdza GET /api/chat. Oczekiwane wartości po konfiguracji:
- openaiConfigured: true
- cloudflareConfigured: true

DANE I BEZPIECZEŃSTWO
---------------------
- Klucz OpenAI przechowuje Cloudflare jako zaszyfrowany Secret.
- Klucz nie jest przechowywany w ZIP, wrangler.toml, WEB_PUBLISH ani w D1.
- Klucz nie jest widoczny w przeglądarce.
- Czat przekazuje treść wiadomości do skonfigurowanego dostawcy AI.
- Nie wpisuj haseł, kluczy BitLocker ani danych klientów.
- Historia rozmowy jest synchronizowana z D1 tylko po dobrowolnym włączeniu synchronizacji.

KOSZTY
------
OpenAI API jest rozliczane osobno od abonamentu ChatGPT. Sam klucz nie kosztuje,
ale generowanie odpowiedzi jest płatne według użycia. Cloudflare Workers AI również
ma własne limity i zasady rozliczeń. Sprawdź aktualne ceny przed większym użyciem:
https://developers.openai.com/api/docs/pricing
https://developers.cloudflare.com/workers-ai/platform/pricing/
