FIX103 — WINDOWS CMD NODE RESOLVER REWRITE
Data: 2026-11-08

1. Naprawiono błąd „The system cannot find the batch label specified - TRY_NODE”: aktywny resolver FIX103 nie używa CALL :TRY_NODE ani subroutyn etykietowanych w CMD.
2. Naprawiono błąd „The input line is too long”: usunięto rozwijanie całego PATH w łańcuchu ENDLOCAL i nie modyfikuje się już PATH w CMD.
3. Wykrywanie i sprawdzanie Node.js przeniesiono do osobnego skryptu PowerShell resolve-node-fix103.ps1; CMD odbiera krótkie pliki wynikowe.
4. Weryfikacja sprawdza rzeczywiste uruchomienie node.exe --version oraz akceptuje Node.js 20+.
5. Zachowano wybór pliku node.exe, ręczne wklejenie ścieżki i projektowy zapis NODE_EXE.path.
6. Główny start, konfiguracja OpenAI, przygotowanie Wrangler, diagnostyka i testy używają wspólnego resolvera FIX103.
7. Przy przygotowaniu Wrangler preferowany jest npm-cli.js z katalogu instalacji Node.js; sam Wrangler jest uruchamiany jawnie przez NODE_EXE.
8. Dodano 13 testów FIX103 i podłączono je do lokalnego preflight OneClick oraz Watchera.
9. Zaktualizowano historyczny test FIX102 tak, aby poprawnie akceptował zakończenia linii CRLF w plikach Windows CMD.
