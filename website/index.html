NAJCZĘSTSZE PYTANIA

Pomoc i odpowiedzi

Czy program jest bezpłatny?

Tak. Pobranie i korzystanie z udostępnionego wydania jest bezpłatne. Strona nie wymaga zakładania płatnego konta ani wykupienia abonamentu.

Czy strona działa na całym świecie?

Tak. Strona jest publiczna i przeznaczona dla użytkowników na całym świecie. Dostępność pobierania może zależeć od lokalnych ograniczeń sieciowych i dostępności usług GitHub.

Czy program automatycznie naprawi każdy komputer?

Nie. Program udostępnia narzędzia diagnostyczne i naprawcze, ale wynik zależy od rodzaju usterki, sprzętu i stanu systemu. Niektóre operacje wymagają decyzji użytkownika i uprawnień administratora.

Skąd pobierać aktualizacje?

Wyłącznie z oficjalnego repozytorium GitHub Komputerowego Centrum Serwisu. Aktualizator weryfikuje pliki za pomocą sum SHA-256.

Co zrobić, gdy pobieranie nie jest jeszcze dostępne?

Oznacza to, że nie znaleziono publicznego wydania Stable z kompletem wymaganych plików. Kliknij „Sprawdź ponownie” albo otwórz oficjalną stronę wydań GitHub. Dostępność może zależeć od sieci i usług GitHub.

POTRZEBUJESZ POMOCY?

Zgłoś problem online

Przygotuj zgłoszenie techniczne. Formularz nie wysyła danych automatycznie — otworzy formularz GitHub z przygotowaną treścią, którą możesz sprawdzić i samodzielnie opublikować.

Uwaga: zgłoszenia GitHub są publiczne

Zanim przygotujesz zgłoszenie, usuń z opisu dane klientów, hasła, tokeny, klucze licencyjne, numery seryjne, adresy e-mail i prywatne raporty. Nie załączaj poufnych plików.
