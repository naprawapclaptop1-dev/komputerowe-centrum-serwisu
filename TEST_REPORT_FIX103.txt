NAUKA OD A DO Z — RAPORT TESTÓW FIX103
Data: 2026-11-08

CEL
Naprawić trzy błędy CMD zgłoszone podczas uruchamiania FIX102:
- The system cannot find the batch label specified - TRY_NODE
- The input line is too long
- The syntax of the command is incorrect

DIAGNOZA
Stary resolver uruchamiał CALL :TRY_NODE z wielu bloków/pętli CMD. Dodatkowo eksport zmiennych po ENDLOCAL rozwijał cały PATH w jednym wierszu polecenia. Duże wartości PATH mogły przekroczyć limit parsera CMD.

POPRAWKA FIX103
- Aktywny resolver nie zawiera CALL :TRY_NODE.
- Długie skanowanie ścieżek wykonuje osobny skrypt PowerShell uruchamiany parametrem -File.
- CMD czyta wyłącznie krótkie pliki node.path i node.version.
- Node jest weryfikowany przez --version w PowerShell i ponownie w CMD.
- Nie ma rozszerzania ani przepisywania PATH przez CMD; żaden `set PATH=...%PATH%` nie występuje w resolverze.
- Główny start i narzędzia uruchamiają Node przez pełną ścieżkę NODE_EXE.
- Wrangler używa bezpośrednio NODE_EXE; przy instalacji preferuje npm-cli.js z folderu Node.
- NODE_EXE.path zapamiętuje zaakceptowaną ścieżkę w folderze projektu.
