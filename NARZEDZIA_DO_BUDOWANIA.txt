NARZEDZIA DO BUDOWANIA FIX014

1. C# compiler .NET Framework 4.x — wymagany do skompilowania aplikacji.
2. Inno Setup 7.1.1 — zalecany do instalatora Windows 7 SP1 i nowszych.
   Oficjalna strona pobierania: https://jrsoftware.org/isdl.php
3. Inno Setup 5.6.1 — opcjonalny, jeśli potrzebny jest osobny instalator dla Windows XP SP3.
   To ostatnia wersja Inno Setup obsługująca stare systemy Windows 2000/XP/Server 2003.
4. .NET Framework 4.0 Full lub nowszy — wymagany runtime aplikacji. Na XP wymagany jest XP SP3.
   Oficjalne informacje .NET: https://learn.microsoft.com/pl-pl/dotnet/framework/install/on-windows-and-server

Po instalacji Inno Setup uruchom BUILD_ALL.cmd. Skrypt wyszuka ISCC.exe w standardowych folderach.
Dla XP instalator może powstać tylko wtedy, gdy zainstalowano kompilator Inno Setup 5.6.1.
W tym pakiecie nie ma gotowych EXE — środowisko przygotowujące ZIP nie ma Windows/csc.exe/ISCC.exe.
