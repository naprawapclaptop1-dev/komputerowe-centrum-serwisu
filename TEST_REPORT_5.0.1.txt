TEST REPORT — NAPRAWA PC AKADEMIA SERWISU PRO 5.0.1
NAVIGATION & SIDEBAR FIX

ROOT CAUSE
The app event initializer attempted to bind an event to the absent optional element #startDiagnosis without a null guard. That TypeError interrupted bindEvents(), so event handlers registered later (including the quick procedures list) were never attached.

FIXES
- Guarded event registration for optional elements so one missing control cannot abort the rest of bindEvents().
- Added a capture-phase navigation fallback for #openAllRepairs and [data-open-repair].
- Added public, guarded bridges ACADEMY_SHOW_VIEW and ACADEMY_OPEN_REPAIR.
- The repairs route refreshes the list before display.
- Added a mobile sidebar close button.
- Aligned responsive breakpoint with the existing 900px mobile navigation breakpoint.
- Made the sidebar sticky below the topbar on desktop, independently scrollable, and corrected its viewport height.
- Quick repair titles wrap to two lines; full procedure button is visually prominent and keyboard accessible.
- Updated the service worker cache and asset query versions to 5.0.1.
- Both publication validation stages now verify the repaired controls and sidebar rules.
