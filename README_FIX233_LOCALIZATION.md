# FIX233 — preferencja języka PL/EN

- Nowy panel FIX231–FIX239 ma tłumaczenia PL/EN dla głównych nagłówków i przycisków.
- Preferencja języka jest zapisana lokalnie w `academyLanguage` i współdziała z istniejącym przełącznikiem treści kursowych.
- Istniejący silnik lekcji nadal korzysta z własnych pól tłumaczeń. Nie wszystkie historyczne widoki i materiały mają kompletne tłumaczenie angielskie — to nie jest deklaracja pełnej lokalizacji całej platformy.
