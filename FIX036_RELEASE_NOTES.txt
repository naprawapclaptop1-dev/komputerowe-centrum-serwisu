WHAT CHANGED
1. PC Migration PRO: create a migration package from any selected folder.
2. Store package on USB/external disk or reachable network share (SMB over LAN/Wi-Fi).
3. SHA-256 manifest, size verification, duplicate-entry checks and path traversal protection.
4. Restore the verified package to a selected folder on the destination PC.
5. Added RUBINOWY, SŁONECZNY and OCEANICZNY themes (10 total).
6. Retained all existing module routes and app-data paths.

LIMITS / SAFETY
- The tool transfers files and directory structure. It does not clone installed applications, Windows activation, TPM-bound secrets or vendor license entitlements.
- Some application settings require the application to be closed before copying and may require reinstall/re-authentication on the new PC.
- LAN/Wi-Fi transfer uses a Windows SMB share selected as the package destination; configure share permissions and firewall intentionally.
- Bluetooth is not a high-throughput migration transport. Transfer the package using Windows Nearby Sharing where supported, or use USB/LAN.
- Reparse points/junctions are skipped to prevent accidental traversal outside the selected folder.
- Verify the package before restore. Restore can overwrite files only after explicit confirmation.
