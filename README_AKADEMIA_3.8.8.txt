NAPRAWA PC — AKADEMIA SERWISU PRO 3.8.8

Wydanie wyglądu i UX oparte na stabilnej wersji 3.8.7.

INSTALACJA ŁATKI:
1. Zatrzymaj działający obserwator przez Ctrl+C.
2. Wykonaj kopię folderu G:\AKADEMIA_SERWISU_PRO\WEB_PUBLISH.
3. Rozpakuj łatkę do G:\AKADEMIA_SERWISU_PRO z zachowaniem struktury katalogów.
4. Uruchom dotychczasowy URUCHOM_AKADEMIE.cmd.

Zakres: WEB_PUBLISH/index.html, WEB_PUBLISH/assets/app.js, WEB_PUBLISH/assets/theme-380.css.
Nie zastępuj ONECLICK_AKADEMIA.js, wrangler.toml, migracji ani funkcji Pages.

Po uruchomieniu otwórz procedurę naprawy i sprawdź, czy modal jest wyśrodkowany, nie jest obcięty przy pasku bocznym, a sekcje układają się responsywnie.
