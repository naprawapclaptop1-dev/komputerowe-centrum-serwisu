# FIX199 — Warsztat geometrii 3D

Warsztat generuje edukacyjną scenę z siatek wielokątów i renderuje ją z perspektywą na Canvas 2D. Zawiera płytę główną, CPU/socket, pamięć DIMM, VRM, M.2, PCIe/GPU, chipset, porty i ścieżki PCB. Obsługuje obracanie, zoom, klawiaturę i wskazywanie części.

Model jest edukacyjnym przybliżeniem, nie plikiem CAD, skanem płyty ani odwzorowaniem konkretnego produktu. Nie wykonuje pomiarów elektrycznych.
