FIX095 SAFE CLEANUP SCOPE

CLEANED:
- Old unused .tmp/.temp files from current user's TEMP and Windows TEMP (14 days by default).
- Stale temporary KCS source-sync clones created by this product (24 hours by default).
- Regenerable cache files from explicitly named locations: Chrome, Edge, Firefox, Brave, Vivaldi, Opera, Discord, classic Microsoft Teams, Windows DirectX D3DSCache, NVIDIA DXCache/GLCache/NV_Cache, AMD DxCache/GLCache/DxcCache, Intel ShaderCache/ComputeCache. App cache age threshold defaults to 0 days; set AppCacheAgeDays to a positive number to keep newer cache files.

PRESERVED:
- Cookies, browser sessions, saved passwords, browser history, extensions and browser preferences.
- Application profiles, settings, databases, user documents, downloads, save data, project files, installed applications, registry, installers, portable builds, node_modules and .tools.
- Locked, system and reparse-point files.

The cleaner logs every deletion or skip in dist/build-logs/SAFE_TEMP_CLEANUP.log.
