# FIX218 — zagregowana analityka administratora

Panel admina pokazuje zagregowane liczniki kont, sesji, zdarzeń, prób egzaminów, certyfikatów, klas i zdarzeń bezpieczeństwa. Endpoint wymaga istniejącego ADMIN_REVIEW_TOKEN. Nie zwraca danych poszczególnych użytkowników ani sekretów. Liczniki wymagają aktualnych migracji produkcyjnej D1.
