KOMPUTEROWE CENTRUM SERWISU — FIX085

Naprawa błędu `Filename too long` podczas synchronizacji GitHub.

1. Usunięto lokalny cache `.tools` z indeksu repozytorium: 716 wpisów (257 plików i 459 katalogów).
2. Dodano `.tools/` do `.gitignore`.
3. Git clone używa `git -c core.longpaths=true clone`, a więc ustawienie działa przed checkoutem.
4. Lokalny `.tools` nadal pozostaje na komputerze użytkownika i jest pomijany przez Robocopy.
5. Dodano kontrolę regresyjną FIX085 do jednego głównego CMD.

Repozytorium: naprawapclaptop1-dev/komputerowe-centrum-serwisu
Wersja aplikacji: 1.0.0.69 (bez zmiany)
