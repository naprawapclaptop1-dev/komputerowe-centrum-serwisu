NAUKA OD A DO Z — CHANGELOG 6.8.0 FIX42
======================================
Data: 2026-11-04

DODANO
- Realny Warsztat Serwisowy PRO jako nową zakładkę w istniejącym Centrum Nauki.
- Boardview Studio: lokalny PDF preview i importer CSV/JSON z koordynatami,
  mapą komponentów, wyborem elementu, szablonem CSV i eksportem JSON.
- Electronics Lab EDU: multimetr z blokadą niebezpiecznych trybów, model
  zasilacza z ograniczeniem prądu, oscyloskop i log pomiarów.
- Diagnostic Copilot: deterministyczne hipotezy dla typowych awarii,
  procedury, warunki STOP, historia i ręczne przekazanie do czatu AI.
- Service Desk: lokalna karta przyjęcia, statusy, kosztorys, test końcowy,
  raport HTML do wydruku / PDF.
- Hardware Master: baza profili komponentów EDU, filtr parametrów i magazyn.
- Windows Rescue: checklisty BCD, BSOD, SMART i odzyskiwania danych.
- Repair Championship: losowy quiz z zapisem wyniku.
- Eksport/import lokalnej kopii JSON FIX42.
- Test regresji FIX42 i skrypt WYKONAJ_TESTY_FIX42.cmd.

ZINTEGROWANO
- FIX42 jest nową zakładką w panelu Mój pulpit nauki PRO.
- Rozszerzono nawigację FIX40, pre-cache PWA i cache namespace FIX42.
- Dodano kontrakt FIX42 do One-click publisher i Auto Publish Watcher,
  w tym kontrolę zdalnych zasobów po publikacji.
- Aktualizowano identyfikator build w release.json, meta HTML i API statusu.
- Zachowano wszystkie wcześniejsze moduły, bazy i materiały FIX41/FIX40.

OGRANICZENIA / UCZCIWY ZAKRES
-----------------------------
- PDF jest podglądany lokalnie; po odświeżeniu należy wybrać plik ponownie.
- Boardview import w tym wydaniu obejmuje CSV i JSON; nie obsługuje
  automatycznie wszystkich zamkniętych formatów producentów.
- Przyrządy są symulatorami edukacyjnymi bez połączenia z USB/urządzeniami.
- Diagnostyka lokalna jest regułowa, nie jest generatywną AI ani pewną diagnozą.
- Katalog części EDU służy do nauki filtrów parametrów, nie potwierdza zamienności.
- Windows Rescue przedstawia checklisty i nie wykonuje operacji na systemie.
- Zlecenia, magazyn i dzienniki są lokalne; nie ma synchronizacji kont/zespołu.

BEZ ZMIAN
---------
- Wersja produktu pozostaje 6.8.0.
- Nie usunięto modułów FIX41/FIX40.
- Nie wykonano publikacji produkcyjnej ani migracji D1.
